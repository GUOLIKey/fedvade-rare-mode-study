# 服务器端层次聚合（Multi-CA）

**问的问题**：用解析合并替换"重采样 100 个点再梯度重估"，能否改善全局聚类。

方法：对角高斯 2-Wasserstein 距离、尺度归一化 Bures 排序、complete-linkage 凝聚合并、
加权矩匹配更新参数、保留 Macro(2)/Micro(10) 两级。

**结论**：冻结实验中，Multi-CA（K=7）与**同容量平面合并（K=7）的叶分量逐位相同**，
指标一致（ARI 0.6192）。层次结构只决定合并顺序，不改变最终叶子。
完整回路（warm start）下 ARI 崩溃。详见 `docs/reports/10`、`11`、`12`。
