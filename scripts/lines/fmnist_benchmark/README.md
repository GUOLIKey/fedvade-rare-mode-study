# 碎片化基准

**问的问题**：换一个稀有类可分的数据集，FedVaDE 还会不会丢类？

**数据**：Fashion-MNIST 展平 784 维。三组——平衡版（每类 1000 条）、长尾版 ρ=10、长尾版+作者原划分。
划分用类内 K-Means 把每个类切成 4 个碎片分给 10 个客户端，零样本重叠。

**子命令**

| 命令 | 做什么 |
|---|---|
| `prepare` | 下载并缓存平衡版 / 长尾版 |
| `check` | 训练前检验：每类 1-近邻纯度、集中式 GMM 的 ARI、划分统计 |
| `run` | 跑一次完整联邦训练（委托 common/train.py） |
| `driver` | 三组 × 3 种子，训练 + 评估 |
| `eval` | 对已有 run 算 Global ARI / Purity / NMI |

**结论**：碎片化划分下 ARI 0.22–0.26，作者划分下 0.38；覆盖率比值 1.11–1.18 vs 1.01。详见 `docs/reports/14_fmnist_baseline.md`。
