# 覆盖率指标

> **真实缺类对照更新：** 删除Fashion-MNIST凉鞋/包/短靴后，ratio仍可能处于1–1.5，不能据此排除丢类；见根目录报告21。下方历史“所有类都保留”的解释已撤回。

> **审核后的当前说明：** 历史全局tau指标不用于当前结论。默认定义与README一致；新CLI强制|G|=|R|，明确生成/划分种子并运行有限的合成阳性对照。距离比不等于分布等价。
> 正确入口和能力边界见 [代码说明](../../README.md)；下方为历史线路说明，其结论以根README和结论状态表为准。


**问的问题**：我们自造的覆盖率指标可不可信。

旧指标用全局统一阈值 τ（所有样本最近邻距离的中位数），对类内散布大的类系统性不利：
class 8 的样本彼此相距 21.4，用 12.97 去要求它本来就不可能达到；class 1 彼此只隔 8.13，很容易满足。

修好之后的定义：

```
真实数据按类分层对半分：参考集 R、查询集 Q
模型生成 |R| 条样本 G
ratio(c) = median_{q∈Q_c} d(q, G) / median_{q∈Q_c} d(q, R)
```

阈值、样本量、类内几何全部对齐，不含任何超参。

**内建自检**：`--self-check` 把生成集换成参考集本身，每个类的 ratio 必须精确等于 1.0，
不通过则拒绝输出结果。实测 10/10 类均为 1.000。

**结论**：用这个指标，"某些类被系统性丢弃"不成立——所有类的 ratio 都在 1.0–1.5 之间，
真正的差异来自划分方式（作者划分 1.009 vs 碎片化划分 1.11–1.18）。详见 `docs/reports/16_correction.md`。
