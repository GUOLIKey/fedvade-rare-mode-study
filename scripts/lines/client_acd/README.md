# 客户端自适应聚类（ACD）

**问的问题**：让客户端用 Fed-HIRE 的竞争学习自己切簇，再把结果转成 FedVaDE 需要的
`(π, μ, σ²)`，能否改善全局聚类。

ACD 使用作者 FCPL 源码（commit `c116c835`），未改内部逻辑；参数由矩估计得到
（`π = n/N`、population 方差、`var = max(var, 1e-6)`）。含六组局部对照与接口验证。

**结论**：平均局部 K = 91.2，85% 概率质量落在支持 <5 的分量；全局
ACD − 原始 = +0.0008 ± 0.0184，ACD − 同K对照 = −0.0016 ± 0.0328。**无改善。**
失败机制：每客户端平均只被采到 9.3 / 91.2 个分量。详见 `docs/reports/08`、`09`。
