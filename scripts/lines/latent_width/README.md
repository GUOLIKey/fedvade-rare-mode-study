# 潜空间宽度

> **审核后的当前说明：** 已测三seed中未观察到明显覆盖改善，不等于证明维度没有影响；不同代际评价须分别命名。
> 正确入口和能力边界见 [代码说明](../../README.md)；下方为历史线路说明，其结论以根README和结论状态表为准。


**问的问题**：生成覆盖是不是被 10 维潜空间卡住了？

三组宽度 10 / 20 / 30，各 3 个训练种子。10 维那组复用碎片化基准线的结果。

**结论**：ARI 0.259 / 0.304 / 0.278（20 维最好，但幅度与种子噪声同量级）；
覆盖率 1.113 / 1.106 / 1.120 —— **潜空间宽度对覆盖没有影响**。详见 `docs/reports/17_hiddim_sweep.md`。
