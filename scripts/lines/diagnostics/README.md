# 丢失定位

**问的问题**：某些类生成不出来，问题出在编码器、客户端局部 GMM、服务器分量，还是解码器。

| 子命令 | 检查什么 |
|---|---|
| `mode-loss` | 服务器各分量装哪些类、死分量数、客户端局部 GMM 是否形成对应分量、潜空间 1-近邻纯度、每分量期望采样数 |
| `decoder` | 重构误差（服务器 vs 客户端）、oracle 覆盖率（把真实样本编码再解码，绕开 GMM 采样）、逐类类别均值基线 |

**结论**

- 潜空间里目标类高度可分（class 5/8/9 的 1-近邻纯度 0.76 / 0.87 / 0.86，随机水平 10%）
- 服务器解码器与客户端解码器**完全相同**（重构误差差 0.2%）——问题不在聚合
- 但这两条在修好指标之后都不再支持"某类被丢弃"的结论，见 `coverage_metric/README.md`

详见 `docs/reports/15_fmnist_diagnosis.md`。
