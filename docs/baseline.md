## 2. 必须声明的限制

**本基线是单次训练的结果。** 同一配置在三个训练种子上为 0.5774 / 0.6381 / 0.3212。因此：

- 对外表述只能是"单次训练结果"，不能写成"FedVaDE 的平均性能"。
- 后续任何方法的比较，**必须在相同训练种子上配对进行**；只报一次运行无法区分方法与种子运气。

## 3. 历史值，不再作为基线

- **0.6140 / 0.6053（F01）**：Round-7 在 16 个配置、单个训练种子上按同一套 ARI 选出的配置，其峰值轮次的取值。`SEARCH_PROTOCOL.md` 自注 "None of these ARI-selected scores is an unbiased independent test result"。
- **0.6053 的三种子分布**：0.6053 / 0.6509 / 0.4291，均值 0.5618 ± 0.1171。
- 这些只能作为历史参考引用。

## 4. 实验协议

1. 每个配置至少 3 个训练种子；比较时按种子配对。
2. 必须同时报训练种子 0/1/2 的结果与推断种子标准差，二者不可混用（历史F01例中SD相差约26倍，非普遍常数）。
3. 必须用完整 300 轮原流程；不使用冻结客户端或缩短轮数的代理实验（不同代理实验的偏差不应视为固定常数）。
4. 全流程单次约 305 秒（CPU 单线程）。
5. **基线必须在与干预相同的会话/宿主内重跑**；历史两宿主曾相差约0.009 ARI，此差值不是通用漂移常数。
