## 四、超参网格里的取值

| 旋钮 | 试过的值 | 结论 |
|---|---|---|
| `sample`（服务器每轮采样数） | 50 / **100** / 200 / 500 / 1000 | 仅单seed @100的已测网格最高；未排除预算瓶颈 |
| `pretrain`（预训练轮数） | 5 / 10 / 20 / **50** / 100 / 150 | 响应锯齿状，10 的单种子高分未在三seed配对比较中形成稳定改善 |

## 九、使用约定

1. 写报告时先说名字，需要追溯时再括注旧标签，例如"低方差组合（原 B4）"。
2. 新实验一律直接起名字，不再用字母数字编号。
3. 旧标签只在 `docs/reports/` 的历史报告里保留原样，不改动，以免与当时的记录不一致。

## 十、代码文件命名

代码按「一条线路一个文件夹」组织，共享逻辑放在 `common/`。完整说明见 `scripts/README.md`。

| 名字 | 位置 | 说明 |
|---|---|---|
| 共享模块 | `scripts/common/`（9 个文件） | 距离、指标、模型、采样、数据、训练循环、局部 GMM、评估 |
| 碎片化基准 | `scripts/lines/fmnist_benchmark/main.py` | 数据准备 + 前置检验 + 训练 + 三组驱动 + 评估 |
| 潜空间宽度 | `scripts/lines/latent_width/main.py` | 10/20/30 维扫描 |
| 客户端 DPGMM | `scripts/lines/client_dpgmm/main.py` | dump / precheck / driver / eval |
| 客户端自适应聚类 | `scripts/lines/client_acd/main.py` | ACD 局部实验与接口验证 |
| 服务器端层次聚合 | `scripts/lines/server_multica/main.py` | Wasserstein + 层次合并 + 矩匹配 |
| 服务器端重加权 | `scripts/lines/server_reweight/main.py` | 采样下限与责任度下限补丁 |
| 覆盖率指标 | `scripts/lines/coverage_metric/main.py` | size-matched 覆盖率，含自检 |
| 丢失定位 | `scripts/lines/diagnostics/main.py` | mode-loss / decoder 两个诊断 |
