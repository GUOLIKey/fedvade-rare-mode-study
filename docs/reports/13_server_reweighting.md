# 稀有模式：服务器端重加权实验（rare_global_v1）

> **2026-11-26 审核更正（优先于下方历史正文）：** 本报告仅一个训练seed；覆盖率使用旧全局阈值，不能作为可靠的跨类覆盖证据。低1-NN纯度不证明无可学结构；标量惩罚占比不证明梯度可忽略，K瓶颈和形状变糊均未被隔离验证。
> 当前结论与复现边界见 [README](../../README.md) 和 [结论状态](../conclusion_status.md)。

> **⚠ 重要局限，结论不可推广。**
>
> 本实验在 yeast 上完成。事后测得 yeast 的稀有类在**原始输入空间**的 1-近邻纯度只有
> 0.018 / 0.029 / 0.000（占比 2.3% / 1.5% / 0.3%），**低于随机水平**，即数据里不存在可分的稀有结构。
> 因此本报告的负面结果只能说明"在这份数据上无效"，不能用来否定服务器端方向。

日期：2026-11-25。目标：让 FedVaDE 的**全局生成模型**覆盖客户端稀有类，只改服务器端，客户端不动。

## 1. 设计

数据集 yeast（1484 条，8 维，10 类，尾部 3 类共 55 条）。基线配置：作者源码 + alpha 0.05、lr 0.002、sample 100、pretrain 50、rounds 300、训练种子 1。评估 10 个推断种子。

| 组 | 采样端 | 损失端 |
|---|---|---|
| A | 原样（每轮 100 点按全局 π 抽） | 原样 |
| B | **每局部有分量至少 1 点**（全局 66 个分量） | 原样 |
| C | 原样 | **责任度均值低于 1/(2K) 的分量加惩罚**（β=4） |
| D | 两者都加 | 两者都加 |

补丁位置：`gmm_sampling` 的 `np.random.choice`（采样端）；`ELBO_Loss_server` 的 `return Loss` 前（损失端）。作者其余代码未动。

## 2. 结果

| 组 | ARI | 稀有覆盖率 | 多数类覆盖率 | 生成落在稀有区 | 死分量 | 最大分量占比 | 稀有类分量数 |
|---|---:|---:|---:|---:|---:|---:|---:|
| A | 0.1604 | **0.351** | 0.622 | 9.8% | 3 | 0.722 | 0 |
| B | 0.1430 | 0.291 | 0.531 | **15.8%** | 2 | **0.542** | 0 |
| C | 0.1604 | 0.351 | 0.622 | 9.8% | 3 | 0.722 | 0 |
| D | 0.1430 | 0.291 | 0.531 | 15.8% | 2 | 0.542 | 0 |

A 组与 round17 的 yeast 基线逐位一致（0.1604 / 0.351），确认补丁在关闭时不改变行为。

## 3. 结论

1. **使用量下限（C）完全没生效。** D 组与 B 组逐位相同，证明 C 的贡献为零。原因可量化：3 个分量使用量为 0，惩罚项 = β·Σ(0.05−0)² = 4×3×0.0025 = 0.03，而同期 server loss ≈ 2.0，占比 1.5%，梯度可忽略。**这不是想法被否定，是这个想法没有被真正测到。**

2. **采样下限（B）改变了模型行为，但方向有害。**
   - 按设计生效：生成样本落在稀有区的比例 9.8% → 15.8%，最大分量占比 0.722 → 0.542，死分量 3 → 2。
   - 但稀有覆盖率从 0.351 降到 0.291，多数类覆盖率和 ARI 同时下降。
   - 解释：把 10 个服务器分量强制摊到 66 个局部分量上，每个分量都被拉向多个局部碎片，结果是"位置对、形状糊"。覆盖率要求足够接近真实稀有样本，模糊的生成达不到。

3. **四组都没有产生任何以稀有类为主的分量**（rare_components = 0）。服务器 GMM 的分量分配从未把槽位给到稀有类。

## 4. 判断

"服务器端重加权"这一族修法在此设定下不成立：**加权能把质量推到稀有区域，但不能提高精度；真正的约束是服务器只有 K=10 个分量，而局部有 66 个。**

下一个待验证的假设是**服务器容量**（放宽 K），而不是继续调权重。但需注意：yeast 的基线 ARI 只有 0.16，大类本身就没有分好，容量假设即使成立也未必改善稀有模式。
