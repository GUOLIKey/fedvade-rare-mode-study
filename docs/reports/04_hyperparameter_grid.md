# F01 超参网格与多种子验证（round13）

日期：2026-11-25。目标：在 F01 基线上做超参网格搜索，判断能否稳定超过基线。结果：**不能，且原因不在调参，而在训练种子方差。**

## 1. 设计

只搜索作者 `main.py` 暴露、round-7 网格从未覆盖的两个旋钮，其余固定 F01：lr=0.002、alpha=0.05、schedule=epoch、rounds=300、数据划分 seed=42。

- 网格一（训练种子 0）：`sample ∈ {50,200,500,1000}`、`pretrain ∈ {10,20,100,150}`，8 个配置
- 网格二（训练种子 1、2）：`pretrain ∈ {5,10,15,20}`，加基线，10 个配置

runner 使用历史原始脚本副本（`runner_hist.py`，sha256 `1853b513…`）。多种子阶段使用 `runner_seed.py`，与原始脚本的差异只有 4 行：`--seed` 断言放宽、三处 `seed(0)` 改为 `seed(args.seed)`。作者源码未修改。

评估：`evaluate_saved_round6.py`，10 个推断种子，逐 25 轮。同宿主同会话，基线重跑已验证逐位可复现。

## 3. 结论

1. **没有任何配置在 ARI@100 上稳定超过基线。** 唯一在单种子上明显更高的 P010（seed 0 = 0.6804）在 seed 1 是 −0.0900、seed 2 是 −0.0240，三种子配对差为 −0.0130。
2. **基线的训练种子方差是 0.117（@100）/ 0.173（@300）。** 这比本次能找到的任何超参效应都大，也比此前所有报告使用的推断种子噪声大 25 倍。
3. **在此设定下超参调优不可解。** 分辨 0.05 的差异需要每组约 9–10 个训练种子；即使分辨出来，0.05 的收益在 0.12 的噪声下也没有实际意义。
4. `sample` 旋钮已确认耗尽：作者默认的 100 是局部最优点，向两侧移动均下降。这否定了"服务器重采样预算是 Global ARI 瓶颈"的假设。
5. 模型存在**部分训练种子直接不收敛**的情况：BASE seed 2 = 0.4291，P015 seed 2 = 0.1317。

## 4. 对既有结论的影响

此前报告中所有 ±0.0045、±0.0062 均只反映推断种子噪声。`acd_f01_global_v1` 的 D−A = +0.0008 ± 0.0184 是在 3 个实验种子上估的，真实量级应在 0.08–0.12，该对比无法判断方向。**历史上所有小于 0.05 的差异不再构成证据。**
