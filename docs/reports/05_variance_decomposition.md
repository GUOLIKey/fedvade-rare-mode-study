# 方差来源分解实验（round13 / runs_decomp）

日期：2026-11-25。问题：F01 基线的 ARI 在训练种子间波动 SD 0.117（@100），这个方差主要来自**初始权重**还是**训练过程中的随机性**？

## 1. 方法

在作者训练流程上插入一个重新播种点（`_reseed()`，位于 `pre_train` 之前），从而把随机性拆成两路：

- **初始权重**：`_reseed` 之前设随机种子，决定模型参数初始化（影响预训练轨迹与预训练末的 GMM 初始划分）
- **训练流程**：`_reseed` 之后设随机种子，决定 DataLoader 打乱顺序、ELBO 里潜变量采样 `z = randn_like(mu)·exp(logσ²/2) + mu`、以及服务器端 `gmm_sampling` 的 100 点重采样

每次运行固定其中一路、变化另一路。除该插桩外，作者 `main.py`/`model.py` 未修改。

其余参数固定 F01：lr=0.002、alpha=0.05、schedule=epoch、sample=100、pretrain=50、rounds=300。评估为 10 个推断种子。

## 2. 结果（ARI@100）

| 组 | 固定 | 变化 | 三个取值 | 均值 | SD |
|---|---|---|---|---:|---:|
| A | flow = 777 | init = 0/1/2 | 0.3885 / 0.3158 / 0.4115 | 0.3719 | **0.0500** |
| B | init = 0 | flow = 777/778/779 | 0.3885 / 0.5851 / 0.5263 | 0.5000 | **0.1009** |
| C | 无 | (init=flow)=0/1/2 | 0.6053 / 0.6509 / 0.4291 | 0.5618 | **0.1171** |

ARI@300：A 组 0.3513 / 0.2741 / 0.3779；B 组 0.3513 / 0.5481 / 0.3968。

## 3. 归因

方差按加法近似：

- Var(A 初始权重) = 0.0025
- Var(B 训练流程) = 0.0102
- Var(C 两者同时) = 0.0137

0.0025 + 0.0102 = 0.0127，与 C 的 0.0137 接近，说明两路近似可加、交互项很小。

**训练流程贡献约 74%（0.0102 / 0.0137），初始权重贡献约 18%，其余为交互。**

## 4. 第二个发现：流程种子还有主效应

不只是方差。把流程固定在 777 时均值只有 0.3719；换成 778/779 时是 0.5851 和 0.5263。**同一模型、同一优化器，仅数据顺序与采样随机性不同，平均水平差 0.21。**

所以性能主要由训练轨迹落在哪个区域决定，而不是由起点决定。

## 5. 局限

- 每组仅 3 个取值，SD 的估计误差约 ±40%。
- 归因是"两路可加"的近似，没有做多因素方差分析。
- "流程"仍是复合量，包含数据顺序、潜变量采样、服务器重采样三个子成分，本次未拆分。
