# 覆盖率指标的更正与最终结论

2026-11-26。此文更正此前 `PROGRESS_2026-11-26.md` 与 `DIAGNOSIS_2026-11-26.md` 中关于"5/8/9 类生成覆盖率近 0"的结论。

## 1. 旧指标错在哪

旧定义：真实样本中，能在 5000 个生成样本里找到距离 ≤ τ 的比例，τ 取全体真实数据最近邻距离的中位数（12.97）。

两个缺陷：

1. **阈值是全局的。** class 8 的样本彼此相距 21.4，用 12.97 去要求它，本来就不可能达到；class 1 彼此只隔 8.13，用 12.97 很容易满足。指标实际测的是"类的几何形状"，不是模型能力。
2. **样本量不匹配。** 模型生成 5000 条，真实数据 10000 条。生成样本少一半，最近邻距离天然大 1.4 倍。

## 2. 新指标

```
真实数据按类分层对半分：参考集 R（5000）、查询集 Q（5000）
模型生成 |R| 条样本 G
ratio(c) = median_{q∈Q_c} d(q, G) / median_{q∈Q_c} d(q, R)
```

ratio = 1 表示"模型生成的 5000 条和同等大小的真实集一样有用"；比值越大越差。

**阈值、样本量、类内几何全部对齐，不需要任何超参。**

自检：把 G 替换成 R 本身，所有类的 ratio 必须精确等于 1.0。实测通过（10/10 类均为 1.000）。

## 3. 更正后的结果（3 个训练种子均值）

| 组 | 整体 ratio | 各类 ratio（0–9） |
|---|---:|---|
| 平衡 / Clusterlets | 1.113 | 1.15 1.47 1.13 1.12 1.11 1.03 1.04 1.14 1.11 1.20 |
| 长尾 ρ=10 / Clusterlets | 1.184 | 1.15 1.55 1.16 1.17 1.15 1.07 1.09 1.17 1.16 1.32 |
| **长尾 ρ=10 / 作者划分** | **1.009** | 0.97 1.13 1.02 1.03 1.01 0.97 0.95 1.03 1.01 1.17 |
| 平衡 / hid=20 | 1.106 | 1.14 1.45 1.16 1.11 1.13 1.01 1.04 1.10 1.17 1.11 |
| 平衡 / hid=30（2 种子） | 1.114 | 1.09 1.51 1.12 1.16 1.14 1.04 1.04 1.10 1.14 1.20 |

## 4. 结论

1. **"全局模型只覆盖一半类别"不成立，予以撤回。** class 8（包）的 ratio 是 1.11，和 class 0（1.15）基本一样，甚至好于 class 1（1.47）。没有任何一类被系统性丢弃。
2. **所有类的 ratio 都在 1.0–1.5 之间**，即模型样本比同等大小的真实样本差 0–50%，且各类差别不大。
3. **真正起作用的因素是划分方式**：作者划分 1.009（几乎与真实数据等价），零重叠的 Clusterlets 划分 1.11–1.18。
4. **潜空间维度对覆盖率没有影响**（1.113 / 1.106 / 1.114），但对 ARI 有（0.259 / 0.304 / 0.268）。

## 5. 两个指标现在一致

| 组 | ARI@300 | ratio |
|---|---:|---:|
| 长尾 / 作者划分 | **0.380** | **1.009** |
| 平衡 / Clusterlets | 0.259 | 1.113 |
| 长尾 / Clusterlets | 0.217 | 1.184 |

**划分方式同时影响聚类质量和生成质量，方向一致。** 这比"某些类被丢掉"要简单，也更可靠。

## 6. 局限

- 作者划分那一组存在数据量混淆（重叠使 10001 条变成 45639 条记录），划分方式和有效数据量同时变了。
- `hid=30` 只有 2 个种子（第 3 个仍在跑）。
- ratio 只能在同一数据集内比较。
