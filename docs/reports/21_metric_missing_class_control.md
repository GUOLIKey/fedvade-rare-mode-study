# 真实缺类对照：新距离比不能排除类别缺失

2026-11-26。没有训练新模型；直接对已缓存的Fashion-MNIST做已知标签的缺类对照。

## 方法

按每类分层、seed0对半分R/Q。identity用G=R。缺类对照从R中完全移除一个目标类，再以固定seed0从其余类别重复抽样补足，使|G|=|R|。查询仍用原Q中该目标类；计算与coverage v2完全相同的最近邻距离中位数比。这个G是已知缺少该标签类别的真实样本集，不是训练后的生成器。

| 数据 | 被完全删除的类 | ratio |
|---|---:|---:|
| fmnist_bal | 1 | 1.965507 |
| fmnist_bal | 5 | 1.097363 |
| fmnist_bal | 8 | 1.271403 |
| fmnist_bal | 9 | 1.345050 |
| fmnist_lt10 | 1 | 1.992173 |
| fmnist_lt10 | 5 | 1.100001 |
| fmnist_lt10 | 8 | 1.167408 |
| fmnist_lt10 | 9 | 1.265361 |

## 能推出什么

已知缺少凉鞋/包/短靴的对照，ratio仍能落在原“1.0–1.5”的范围内。因此撤回“新ratio落在此区间，所以没有任何类别被系统性丢弃”的排除性推断。合成远距两类阳性对照通过，不代表在实际Fashion-MNIST上具有同等灵敏度。

## 不能推出什么

这个对照不证明实际FedVaDE一定丢类，也不证明距离比没有描述价值。它说明该指标对不同类别缺失的灵敏度不同，不能单独用来判定语义类别存在与否。当前仅将其命名为样本量匹配的最近邻距离比；原稀有模式目标仍未被可靠的类别保留评价解决。
